# 🐬 Dolphin

**Your Flow. Engineered.**

Dolphin is a framework and web platform focused on improving human well-being according to scientific studies. It measures and helps users optimise their lives across four core pillars: **Body, Mind, Lifestyle, and Purpose**. Through targeted assessments, users calculate their "Flow Score" and are guided to focus on the areas they wish to strengthen the most.

Live Prototype: [https://dolphin-puce.vercel.app/](https://dolphin-puce.vercel.app/)

---

## 🛠 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Language:** TypeScript 5.7
- **Styling:** Tailwind CSS 3.4 + Custom CSS Variables
- **Architecture:** Server Components by default; `'use client'` strictly reserved for interactive boundaries.

---

## 🚀 Getting Started (Local Development)

This phase is strictly for developers. The current application is seeded with mock data (a user profile named "Francisco") to simulate a fully integrated backend state.

### 1. Prerequisites
Ensure you have Node.js (v18.17+ recommended) installed on your machine.

### 2. Installation
Clone the repository and install the dependencies:

```bash
git clone <your-repository-url>
cd Dolphin_Beta
npm install
````

### 3. Run the development Server
```bash
npm run dev
````

### Finally, open http://localhost:3000 in your browser to see the result. Enjoy!
